# GD-M06-A1 Pilot Sample Selection

## Purpose

Define the controlled sample used for GD Bible enrichment pilot testing.

The pilot must be reproducible before any archive-wide processing.

## Source Population

Frozen baseline:

- 19,340 research findings
- 2,060 documents
- 106 collections

## Selection Method

Sample selection will use stratification.

Required coverage:

- multiple collections
- multiple document types
- multiple extraction categories
- valid anchor examples
- invalid anchor examples
- documents affected by previous reconciliation

## Sample Size

Target:

Approximately 25–40 documents.

The final sample list must be frozen before processing.

## Required Records

The pilot sample record must preserve:

- document path
- source hash
- collection
- finding identifiers
- anchor status
- selection reason


## Language Scope

Phase 1 pilot:

- English-language source documents only.
- Foreign-language documents excluded from initial pilot.
- Multilingual processing reserved for future expansion.

Reason:

The pilot validates enrichment quality and pipeline behavior, not multilingual capability.

## Selection Priority

Priority order:

1. English Bible-focused documents
2. Existing GD findings
3. Multiple collections
4. Multiple extraction categories
5. Anchor validity coverage

## Processing Rule

The pilot sample is used only for evaluation.

No archive-wide enrichment begins until pilot approval.

## Current Status

Sample definition only.
