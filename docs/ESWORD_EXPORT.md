# e-Sword Export Notes

## Current exporters

GD is generated by:

`scripts/build_esword_bblx.py`

GD+ is generated by:

`scripts/build_esword_gdplus.py`

## GD outputs

- `editions/esword/GD.bblx`
- `editions/esword/GD.bbli`
- `editions/esword/GD.metadata.json`

GD contains the canonical GD custom Bible text with Jesus speech rendered in
Royal Purple `#9B00FF` and no inline Strong's numbers.

## GD+ outputs

- `editions/esword/GD+.bblx`
- `editions/esword/GD+.bbli`
- `editions/esword/GD+.metadata.json`

GD+ uses the same canonical GD Scripture text, adds the verified Strong's
projection, and renders Jesus speech in Aqua `#00E5FF`.

Strong's identifiers remain ordinary e-Sword `<num>` markup so they remain
clickable in supported e-Sword applications.

## Canonical structure

Both editions preserve:

- 66 books
- 1,189 chapters
- 31,102 canonical verses
- unchanged canonical book/chapter/verse coordinates

Generated e-Sword packages are distribution outputs. They must never become
the canonical editing source.

## Seven presentation divisions

Repository metadata may organize the Bible into these presentation groups:

1. Torah
2. History
3. Wisdom
4. Major Prophets
5. Minor Prophets
6. Gospels and Acts
7. Letters and Revelation

These divisions do not merge books, renumber verses, or alter canonical
references.

## iPad / e-Sword HD

The repository directly generates `.bbli` files that have been successfully
imported into e-Sword HD on iPad.

The tested workflow is:

1. Save the `.bbli` file on the iPad.
2. Open it from Safari or the Files app.
3. Tap **Share**.
4. Choose **e-Sword**.
5. Open e-Sword HD.
6. Select GD or GD+ from the Bible versions.

No PC conversion step was required for the tested iPad `.bbli` builds.

Other e-Sword platforms should only be described as supported after their
actual installation and rendering behavior has been verified.
